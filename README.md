# Inventory Management System
A simple Inventory Management System developed using Core Java to manage products. 
stock, and inventory operations through a menu - driven console application.

## Features
1. **Add product**
   - Add a new product to the inventory.
   - Store product details such as ID, name, price, and stock.

2. **View All Products**
   - Display all products available in inventory.

3. **Search product**
   - Search for the project using the id or product name.

4. **Update product**
   - Update existing product information such as name, price etc.

5. **Delete product**
   - Remove a product from the inventory.

6. **Update stock**
   - Increase or decrease the available stock of a product.

7. **View low stock product**
   - Display products whose stock is below the defined minimum level.

8. **Exit**
   -Safely exit the application.
